## Бүтээлч санаа

Портфолио бүхэлдээ **«зургийн дэвтэр дотор аялах тоглоом»** хэлбэртэй. Тоглоомын баатар нь миний нэрийн утга болох Говийн **хулан**. Миний хобби болох зураг зурахыг илэрхийлж **cherry red берет** өмссөн.
Өнгө нь миний дуртай **цагаан · бор · cherry red**. Анимэгээс санаа авсан манга самбар, хурдны зураас, яриан бөмбөлөг, хийсэх интоорын дэлбээ ашигласан.

| Бүлэг | Тоглоомд | Агуулга |
|---|---|---|
| 01 Миний тухай | Номон тавцангаар үсэрч, **9 ур чадварын стикер** цуглуулна. Самбар бүр манга яриан бөмбөлгөөр ярина | Танилцуулга, намтар, ур чадвар |
| 02 Хобби | Зургийн мольберт, анимэ нүдтэй зурагт, ном уншдаг булан, **толгойгоороо тосдог волейболын бөмбөг**, ширээний теннис, биллиард | Хобби (зураг, анимэ, ном), спорт (волейбол, ширээний теннис, биллиард) |
| 03 Бүтээлүүд | 5 зургийн жааз. Жааз бүрийн өмнө ↑ дарвал **манга самбар** нээгдэнэ | 5 бүтээл: зураг, тайлбар, stack, холбоос |
| 04 Холбоо барих | Интоорын модонд хүрэхэд статистик болон холбоо барих мэдээлэл гарна | Имэйл (хуулах), GitHub |

**Унших горим** (`#reading`) нь ижил агуулгыг энгийн гүйлгэдэг хуудсаар харуулна. Багш, ажил олгогч тоглохгүйгээр 1 минутад бүхнийг харах боломжтой.

### Хөдөлгөөнт дизайн (motion design)
- **Micro-interaction:** товч дарахад «пресс» хийгдэх, курсор руу татагдах соронзон товч, 3D хазайдаг хоббигийн карт, стикер цуглуулахад HUD эргэх, имэйл хуулахад товч өөрчлөгдөх, форм алдаатай бол чичрэх, илгээхэд онгоц нисэх.
- **Transition:** горим солих үед дарсан цэгээс эхэлж cherry өнгийн «бэх арчилт» хийгдэнэ. Манга самбар эргэлдэж нээгдэнэ, бүлгийн нэр эргэж солигдоно, бүтээл шүүхэд картууд дарааллан гарч ирнэ.
- **Scroll animation:** IntersectionObserver-оор хэсгүүд гарч ирнэ, гарчгийн доор бэхэн зураас зурагдана, ур чадварын мөр дүүрч хувь тоологдоно. Мөн scroll прогресс мөр, гүйлгэх чиглэлээс хамаарч нуугдаж гарах nav, параллакс хөдөлгөөнтэй.
- **Тоглоомын анимэйшн:** sprite алхалт, үсрэлтийн тоос, интоорын дэлбээ, хуудас нь эргэх ном, зурж буй мольберт, анивчих анимэ нүд.
- `prefers-reduced-motion` тохиргоотой хэрэглэгчид хөдөлгөөнийг автоматаар багасгана.

### Нууцууд 🤫
- Konami код (↑↑↓↓←→←→BA) нь турбо горимыг асааж, сакура сүүлтэй болгоно.
- Номон тавцангийн дээр бараг үл харагдах нууц ном, түүн дээр нууц стикер байгаа.

## Технологи

Ямар ч framework, build алхамгүй. Цэвэр **HTML + CSS + JavaScript (ES modules) + Canvas 2D + Web Audio**.

| Файл | Үүрэг |
|---|---|
| `js/data.js` | Бүх агуулга: профайл, ур чадвар, хобби, бүтээл. Текст солиход зөвхөн үүнийг засна |
| `js/world.js` | Түвшний зураглал: газар, номон тавцан, стикер, объектын байрлал |
| `js/art.js` | Бүх зургийг кодоор зурна: хулан sprite, гэр ахуйн эд зүйлс, 3×5 пиксел фонт |
| `js/game.js` | Game loop (тогтмол 60 FPS алхам), физик, coyote time, jump buffer, волейболын бөмбөг, камер |
| `js/input.js` | Гар болон мэдрэгч товчлуур (held / pressed) |
| `js/audio.js` | 8-bit дуу ба пентатоник аялгуу (oscillator) |
| `js/ui.js` | Toast, манга самбар (`<dialog>`), холбоо барих холбоосууд |
| `js/reading.js` | Унших горим: scroll animation, tilt, соронзон товч, шүүлтүүр, захидлын форм |
| `js/main.js` | Горим солих (нүүр / тоглоом / унших), hooks → UI, өдөр/шөнө горим, нууцууд |

**Хүртээмж:** гараар бүрэн удирдана, `aria-live` зарлал, `<dialog>` нь Esc-ээр хаагдана, skip link, унших горим.
**Responsive:** утсан дээр мэдрэгч товчлуур гарч, камер ойртож, газар товчлуурын дээр байрлана. Billiards утсан дээр босоо эргэнэ.

## Ажиллуулах
```bash
npx serve .          # эсвэл: python3 -m http.server
```
ES modules ашигласан тул файлыг шууд нээхгүй, жижиг сервер хэрэгтэй.
